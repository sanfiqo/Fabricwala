# Archive

Working papers of finished runs, kept for history and not maintained.

- `NIGHT_STATE.md`, `MORNING_REPORT.md`: the log and the final report of the first overnight backend run (13 to 14 Nov 2026) and the notes of the follow-up work on the same file. What is true today is in `docs/PROGRESS.md` (what was done and when) and `docs/PHASES.md` (what is done and what is not).
- `CODEX_NIGHT_PROMPT.md`, `CODEX_API_FOR_SCREENS_PROMPT.md`: the instructions given to the coding agent for those runs. Their numbers (tests, tables, routes) belong to that day.
