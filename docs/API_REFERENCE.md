# API reference

Generated by `OpenApiExportTests` from the real routes and `docs/openapi.json`; do not edit by hand. Run that test with `OPENAPI_EXPORT=1` after a change.
All routes are under `/api/v1`. Who may call: *public* needs no sign-in; otherwise the role (and an approved business where it says so). `limit` is the rate limit group (`auth`, `search`); every client address is also held to a general limit.
Errors are always `{ "code": "...", "message": "...", "fields": { ... } }`. Request and response shapes are the schemas named here, in `docs/openapi.json`. Empty means the route has no typed body or returns plain data.
